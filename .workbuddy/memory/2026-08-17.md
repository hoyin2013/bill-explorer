## 修复：编辑区点候选「要点两次才消失」
- 现象（用户实测两次）：点第一下能带入候选值，但提示弹层不消失；再点一下才消失。
- 第一版修复（只给 mousedown 加 stopPropagation）**无效**——说明漏的不是 mousedown 本身。
- 真正根因：候选 `onMouseDown` 上就 `accept()`（关弹层+提交），弹层在「mousedown→mouseup」整段手势**中途被移除**，随后的 mouseup/click 落到下方 Univer 画布；Univer 把它解读为"点到某格→重新进入该格编辑"，`currentEditCell$` 再次触发、按该格内容重算候选、弹层重开（第一次点只带入值、弹层顽固不消失；再点才消是因为那次碰巧落在空单元格上无候选）。
- 最终修复（`UniverSheet.tsx` + 同步 `ac-e2e-real.html`）：
  - 候选项 `onMouseDown` 只 `e.preventDefault()`（保住编辑器焦点、不丢文本，**先不 accept/不关弹层**）；
  - 候选项 `onClick` 才 `e.preventDefault(); e.stopPropagation(); accept(it)`（accept 挪到 click，弹层陪完整个手势，mouseup/click 始终落在弹层内被吞掉，画布收不到事件→杜绝重开）；
  - `.ac-popup` 容器挂 `onMouseDown`/`onClick` 的 `stopPropagation` 兜底。
- 经验：`accept` 的落盘路径（executeCommand→beforeCommandExecuted 拦截 SetRangeValuesCommand 换值）不依赖 DOM 冒泡，把 accept 从 mousedown 挪到 click 不影响回填。
- 验证：`npx tsc --noEmit -p tsconfig.json` 通过。环境无浏览器自动化，无法 puppeteer 实跑；请本机点一次候选确认弹层一次消失即生效。
- 已回写技能 `univer-autocomplete`：鼠标点选一条改为「accept 必须放 onClick、onMouseDown 只 preventDefault」，并写清真正根因。

## 🔧 FINAL：双击关闭 bug 真正定位 + 修复（前两次修法都漏了「层二」）
- 现象（用户实测）：编辑区点候选，第一下只带入值、提示不消失；点第二下才消失。
- **真正根因 = 两层叠加，缺一层都复发：**
  - **层一（DOM 手势）**：`onMouseDown` 上就 `accept()` 会让弹层在 mousedown→mouseup 中途被移除，mouseup/click 漏到 Univer 画布被解读为「重进编辑」→ 重开。修：accept 挪到 `onClick`，`onMouseDown` 只 `preventDefault`，容器 `stopPropagation` 兜底。
  - **层二（命令同步重发，决定性、前两次都栽在这）**：即使 accept 在 click 上，`executeCommand(SetCellEditVisibleOperation,{visible:false})` 退出链会**同步**触发 `endEdit`→`currentEditCell$` 再 emit 同一格→`recompute` 带旧文本把弹层又开出来。
- **决定性修复（acController.ts `accept`）**：在 `executeCommand` **之前**抓 `guardRow=editRow/guardCol=editCol` 并**立即**置位「重开抑制」`acceptGuardRow/Col`，起 300ms 定时器清零；再调命令。`recompute` 开头若 `acceptGuardRow===row && acceptGuardCol===col` 则 `closePopup()` 并 return。**必须在命令前置位**——命令同步跑完退出链（含 recompute），等返回后才置位会被先跑过的 recompute 绕过。退出 keycode 传 `0`（不移动/不重进）。
- **本机已用 puppeteer（系统 Chrome + puppeteer-core，Vite:5174）真实跑通**：真实键盘输入 "苹" 自然弹出候选 → 点一次 → `window.__ac.open===false` 且目标格 `==="苹果"`，无需第二下。验证脚本 `/tmp/acdiag/diag.js` + 测试页 `ac-e2e-real.html`。
- 已清理 acController.ts 内的 `[TRACE] console.error` 调试日志（生产不应有）。
- 顺带按用户要求**移除 UniverSheet.tsx 手动「保存」按钮**（项目已有连续自动保存 + Ctrl+S 快捷键，按钮冗余）；仅删可见按钮，Ctrl+S 保留。
