## 优化右边面板 + 拆分/合并窗口

用户要求：优化右侧「小票识图」面板，方便操作与查看内容；图片可放大缩小看细节；最好能把该面板**拆成独立窗口**，也能再**合并回**主窗口。

### 拆分/合并窗口实现
- `main.ts`：新增 `detachedImageWin` 变量 + `createDetachedImageWindow()`（创建 BrowserWindow，`loadFile(DIST_HTML, { search: 'detached=image' })`，dev 模式拼 `?detached=image`）；新增 IPC `open-image-detached`（创建窗口）、`attach-image-detached`（关闭窗口）。窗口 `closed` 事件向主窗口发 `image-detached-closed`，主窗口据此恢复右侧面板。
- `App.tsx`：`App` 顶层用 `new URLSearchParams(window.location.search).get('detached')==='image'` 判断，是则渲染 `DetachedImageApp`（只放全屏 `ImageWindow` + `onAttach` 合并回主窗口并 `window.close()`），否则正常三栏。`AppInner` 新增 `handleDetach()`（`setShowImagePanel(false)` + `api.openImageDetached()`）、监听 `image-detached-closed` 恢复面板；`<ImageWindow>` 传入 `onDetach`。
- `ImageWindow.tsx`：`Props` 增加 `detached?/onDetach?/onAttach?`；面板头部 `.image-panel-head-row` 右侧按钮：内嵌态显示「⧉ 拆分窗口」(调 `onDetach`)，独立态显示「⎘ 合并回主窗口」(调 `onAttach`)。
- `preload.ts` / `types.ts`：新增 `openImageDetached()` / `attachImageDetached()`（Promise<void>）。
- `index.css`：新增 `.detached-root`(铺满窗口)、`.image-panel-head-row`(标题左、按钮右推)、`.image-zoom-sep` 分隔线。

### 图片放大缩小查看细节
- 总览预览：顶部新增「－/＋」缩放按钮（原已有滚轮缩放+拖拽平移+双击复位）。
- 单张内联视图：新增滚轮缩放(以光标锚点)+拖拽平移+「－/＋/百分比」按钮+复位；`singleWrapRef` + `singleZoom/singlePan` 状态；拖拽后抑制误触放大(`singleClickGuard`)。
- 放大查看(lightbox)：改为支持**滚轮缩放(光标锚点)+拖拽平移**，顶部条新增「－/＋/复位」按钮；`lbZoom/lbPan` 状态，每次打开复位；`overflow:hidden` 改为平移裁切。
- 复用的 `zoomAround()` 锚点缩放 helper（缩回≤100% 自动归零平移，范围 0.2~8×）。

### 验证
- `npm run build`（tsc + vite + esbuild）全量通过，无类型/语法错误。
- 运行 `npm run electron:preview`：右侧面板头部有「拆分窗口」按钮→点开独立大窗口(可拖到副屏)；独立窗口头部有「合并回主窗口」→点后关闭并恢复右侧面板；单张图可滚轮/按钮缩放、拖拽看细节；点小图弹出 lightbox 同样支持缩放平移。
