## 框选/选区视觉与头部布局修复（下午）
- **去掉"十字高亮"**：原 `.row-active td` / `.col-active` 会给当前激活格所在的**整行/整列**染淡蓝底，导致"没选中的数据也变蓝"。已移除这两处背景，并删除对应 JSX 的 `row-active`/`col-active` class 赋值与 `bandOff` 派生变量。现在**只有选区（`.cell-range`）本身填充蓝色，激活格仅保留 `.td-active` 蓝色描边**——与 Excel 一致。

# 2026-08-15（续）— 账单网格框选交互对齐 Excel

- 修正「跨行框选会多带上一行/整行看起来被选中」问题，并让框选手感与 Excel 一致：
  1. 框选命中改用**几何定位**（`cellAtPoint`/`rowIndexAtY`，按 `tbody.rows` 各行/列 bounding rect 计算），取代 `document.elementFromPoint` + `closest('[data-r]')`。原因：旧方式会被填充柄、行号、单元格内边距干扰，且整行/整列高亮带（`row-active`/`col-active`）在框选时仍显示，造成"整行被选中"的错觉。
  2. 存在多选区域（矩形框选 >1 格，或整行选择 `selRows`）时，**隐藏**整行/整列高亮带，只保留选区 `cell-range` 与活动格边框（`bandOff` 派生值控制）。
  3. 拖拽释放后**活动格回到按下起点**（Excel 习惯：活动单元格=按下处），而非选区左上角。
  4. 新增**行号拖拽连选多行**：`onRowNumMouseDown`（Ctrl/Shift 仍走 onClick 单选/多选）；`onRowNumMouseDown` 与 `onCellMouseDown` 共用 `rangeDragRef`（加 `trs`/`rowMode` 字段），`tbody.rows` 在 mousedown 时缓存一次。
- 改动文件：`src/renderer/components/SheetGrid.tsx`（框选/行号拖拽/高亮带）。`npm run build` 通过。

- 主网格（SheetGrid）交互改动：
  1. 打开账单文件时**不再自动进入编辑态**（移除 load 成功的 `setEditing(true)`），光标仍落在序号列，避免打开就弹出序号编辑框。其余显式操作（识别回填/插入行/复制行/+行按钮）仍保持自动编辑不变。
  2. 序号列新增 **Excel 式拖拽填充序列**：激活序号格右下角渲染 `.fill-handle`，`onFillHandleDown` 拖动按种子整数生成 ±1 递增序列（1,2,3…），拖动区间 `.fill-range` 高亮，支持撤销；种子非整数时退化为整列复制。仅序号列（`noIdx`）生效，避免数量/单价/金额误填充。样式在 `index.css`。
  3. 右键菜单新增 **「序号自动编号」**：`autoNumber(start)` 从右键行向下给序号列填 1,2,3…，末尾行 = 自底向上第一个非空行（不给空白预备行编号）；本行已有整数则续编、否则从 1 起；支持撤销。菜单项放在「复制此行到下方」与「删除本行」之间。
  4. **矩形框选（Excel 式拖拽选数据）**：新增 `selRange` 状态（`{r1,c1,r2,c2}`，锚点+拉伸格）。单元格 `.cell` 的 `onMouseDown` 调 `onCellMouseDown`：左键非编辑态下，移动超 4px 进入拖拽，用 `document.elementFromPoint` + `data-r/data-c`（标在 `<td>` 上）算终点格，`setSelRange` + `setActive`；松手没拖动则 `setSelRange(null)`（单击），拖动则把锚点设到选区左上角并吞掉尾随 click（`suppressClickRef`）。选区单元格加 `.cell-range` 淡蓝高亮（`index.css`）。
     - 选择优先级统一为：**矩形框选 > 整行选择(selRows) > 单格**，封装 `selBlockTSV()`（块→TSV+尺寸）与 `clearSelectionBlock()`（清空内容不删行）。
     - 接入：原生 `onCopy`/`onCut`/`onPaste`、键盘 `Delete/Backspace`→`clearSelectionBlock`、`Ctrl+X`→块复制+清空、输入字符（框选时清空选区后在左上角进入编辑）、右键菜单「复制/剪切/清空内容」、`pasteFromClipboard`（粘贴到选区左上角）。`nav` 方向键与 `openMenu`（右键选区外）会清除框选。
     - 与现有交互无冲突：填充柄 `onMouseDown` 已 `stopPropagation`；行号整行选择独立；双击编辑/`onClick` 单选在 `suppressClickRef` 守卫下正常工作。
