### 日期列自动补全加固（18:10 左右）
- 背景：用户确认日期列「手动敲」与「识图自动填」两种来源都可能有。二者底层存储不同：
  - 载入 / 手敲后 Univer 自动转成**日期序列号**（cell.v=number）；
  - 识图/OCR 填入走 `mapRecognizedToRow` → `parseDateText` → 写**文本** `yyyy-mm-dd`（cell.v=string）。
- 旧实现缺陷：候选 `raw` 原文回写，识图/文本来源会被写成“像日期的文本”，日期列混入非真日期。
- 修复（`univerAdapter.ts` + `UniverSheet.tsx`）：

  - `toItem` 对日期列：无论 raw 是序列号(number) 还是文本日期(string)，一律经 `cellNumOf`/`dateStrToSerial` 解析成**真日期序列号**作为 `raw`，`display` 统一 `excelSerialToDateStr` → `yyyy-mm-dd`。
  - `acceptAc` 写 `raw`(序列号) → 落盘恒为真日期；`pushHistory` 存序列号字符串，回读时 `toItem` 再解析，闭环一致。

### 自动补全「全不提示」致命 bug 修复（18:18 左右）
- 现象：日期列加固后，所有列都不弹提示了。
- 根因（`UniverSheet.tsx` `getColumnValuesWithRows`）：早前「输 9 不出」那轮把列值读取改成 `{value: Number(cellNumOf(value)) ? ...}`，但 `cellNumOf` 对文本返回 `null`，而 **`Number(null) === 0`**（不是 null）。于是整列所有文本值（货品名 `904A货`、备注、文本日期等）都被错归一成 `0` → 候选全是 `display:"0"`，任意输入都匹配不上 → 全不提示。日期列序列号则仍正常。`Number(null)===0` 是被忽略的经典陷阱。
- 修复：`const num = cellNumOf(value); return { value: num != null ? num : value }`（只在确为数字时转 number，文本原样保留）。
- 校验：`tsc --noEmit` + `npm run build:renderer` 均通过。
- 教训：TS 里「`Number(x)` 当可空判断」极易踩 `Number(null)===0`；可空判定应直接 `x != null`。

### 自动补全触发机制重写（轮询替代 input 事件）（18:22 左右）
- 现象：上一条修复后仍「依然是没有提示」——说明根因不在匹配/数据，而在**触发**。
- 旧触发：`document` 捕获 `input` + `findEditor(document.activeElement||e.target)` + `requestAnimationFrame` 延迟读 `editor.textContent`。
  脆弱点：① 首字符 input 早于字符入 DOM（读到空串 → “输 9 一个都没有”）；② 依赖 `document.activeElement` 恰好是编辑器、且 `input` 事件能捕获到；任一不成立即全盘不提示。多次迭代反复“完全不提示”即源于此。
- 新触发（轮询式，已在 `UniverSheet.tsx` 自动补全 `useEffect` 落地）：
  - 每帧 `document.querySelector('[data-u-comp="editor"]')` 直接定位编辑器（与 cleanup 代码同一选择器，编辑期确定性存在）；
  - 读 `editor.textContent`（INPUT/TEXTAREA 读 `.value`），每帧重读 → 首字符下一帧自然补齐；
  - `col:row:text` 去重键（`acLastKeyRef`），仅变化才重算；编辑器消失即 `hideAc()` 并清键；
  - 不依赖 `input` 事件与 `activeElement`。
  - 接纳候选时 `acAcceptingRef` 锁 300ms，避免编辑器关闭前轮询读到刚写入值而重弹。
- 验证：① `tsc --noEmit` + `build:renderer` 通过；② 用独立 node 脚本复刻 `computeSuggestions`/`getColumnValuesWithRows` 算法，对假快照证明「输 9→904A货/904B货、苹→苹果、a→904A货(大小写不敏感)」匹配正确 → 匹配层无误，问题确在触发。
- 关键结论：Univer 单元格编辑器的自动补全**不要用原生 input 事件 + activeElement 猜测**，应轮询 `querySelector('[data-u-comp="editor"]')` + 每帧读文本。
